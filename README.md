# Mini Workspace Explorer

A simple file and folder explorer built with React, TypeScript, Vite, and Tailwind CSS.

## Features

* Create, rename, and delete files/folders
* Nested folder structure
* Open, edit, save, and discard text files
* Search workspace
* Path navigation
* localStorage useed for storing data
* Responsive layout

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Lucide React
